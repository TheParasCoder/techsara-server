Techsara Support Agent

Download and install this small app so your support agent can view your screen and help you remotely.

Download for Windows

Windows 10 / 11  ·  ~80 MB  ·  Free

How to install

1
Click the button above and save the file. If Windows asks, click "Keep".
2
Run TechsaraSupport-Setup.exe. If you see a "Windows protected your PC" warning, click "More info" → "Run anyway".
3
The Techsara Support app will open. You'll see your computer's ID on screen.
4
When you're ready, click "Allow Support Access" — then tell your support agent you're ready.
5
Once the session is done, click "Disconnect Session". Your screen stops being shared immediately.

Your screen is only shared when you click "Allow Support Access".
You can disconnect at any time. The app does not run in the background after you close it from the system tray.
